# Weather Mood App

Time spent: 2 hours 20 minutes

A React weather application built using the OpenWeatherMap API.
Users can search for a city, view the current weather, and record
their mood alongside the weather conditions.

## Features

- Search for weather by city
- Display temperature, conditions, and humidity
- Record a mood corresponding to the current weather
- View mood history
- Persist mood history with localStorage

## Technologies

- React
- JavaScript
- OpenWeatherMap API
- localStorage

## Running the project

1. Install dependencies:

   npm install

2. Create a `.env` file:

   VITE_OPENWEATHER_API_KEY=your_api_key

3. Start the app:

   npm run dev
